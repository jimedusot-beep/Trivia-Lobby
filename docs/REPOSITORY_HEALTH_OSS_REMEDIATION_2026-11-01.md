# Trivia Lobby — Repository health and open-source remediation audit

Date: November 1, 2026. Read-only evidence baseline: main 1841025f8e5be153350e4cb44ad772a417448bab; deployed Render SHA 66aa43a1a7816ef4fc795cf4461de0ab6f2bc6c0. This is an **audit and proposed plan**, not evidence that changes described below have been shipped, tested on physical phones, approved for use, or deployed. Verify current refs before executing any fix.

## Non-negotiable contracts

The television/host is the game; QR-linked phones are one-screen controllers without scrolling or required accounts. Preserve all 31 available modes, server-authoritative results, secret per-player information, same-room rematches, authenticated reconnects, score history, Grand Prix's tested 2D fallback, and the ability to return to trivia. Use disposable data, branches and isolated network tests; avoid changing production live play, database, provider configuration, secrets or billing during research. Record exact SHA and tool version for every measurement. License checks apply to **the specific upstream revision and every asset/file**, not merely a repository banner.

## Snapshot: what was actually verified

- GitHub: 18 open issues; one open PR, #121 (content expansion/rematch rotation). PR #119 was merged into main as 1841025f. All six PR #121 workflows passed at head 3fea0dc2; main CI and integrated acceptance passed at 1841025f; separate main guest-browser workflow was still in progress at the inspected point.
- Production: Render identifies 66aa43a1 as live with auto-deploy off. Successful deployment status is not a physical phone or independent public-HTTP gameplay verification.
- Backups: November 1 scheduled Encrypted recovery backup run 41315192801 passed its disposable PostgreSQL 18 restore drill; the **actual backup job was skipped**. A manual same-provider Neon snapshot exists but does not prove offsite recovery of original documents. Issue #48 remains open.
- Main protection: ruleset 26269964 is active; requires PR, blocks deletion/non-fast-forward and requires production-runtime + integrated Chromium/Firefox/WebKit. It has 0 required approving reviews, does not require core CI job named checks, and strict-up-to-date required checks are false. Issue #49 needs **strengthening**, not initial protection.
- Local simulated live-quiz WebSocket load, PR #119 run 41313021021: 10/25/50/100 simulated connections completed with no failed joins or corrupt scores. p95 question delivery 5/5/10/12 ms and reveal 11/13/21/36 ms, respectively. These are local single-process /ws protocol fixtures, **not** 100 physical guests, not Render production and not equivalent to Grand Prix's guest socket.
- Earlier headless race benchmark, run 41140382580: 3D render rAF p95 ~166.7 ms; 2D ~16.7 ms; restored 3D ~133.4 ms, 202 reported draw calls. Software WebGL virtualization is a possible confound. Not proof of actual TV FPS or the current main's 3D performance.
- Standardized full-host-and-phone-browser completion was verified for Four in a Row and a five-round Quiz in PR #119. The other **29 games** still lack the same certification; engine and unit test coverage is wider.

## Candidate open-source components and decisions

These tools were researched from their upstream official project/license pages. License scope applies to the identified source project only. **No dependency, binary, third-party game source, or asset pack is imported by this audit.** Pin a reviewed upstream revision and archive hash before any later import.

| Candidate and upstream | Stated license | Proposed integration decision |
| --- | --- | --- |
| [Restic](https://github.com/restic/restic) | BSD-2-Clause | Preferred optional *external* encrypted offsite snapshot of dumps and private originals, after consistent export. Compare recovery procedure with existing encrypted backup, no automatic double encryption assumption. |
| [Kopia](https://github.com/kopia/kopia) | Apache-2.0 | Alternative backup operator tool with encryption/deduplication and many storage backends. Choose one, not both, after full isolated restore. |
| [Locust](https://github.com/locustio/locust) | MIT | Python test runner for controlled realistic socket loads; build against Trivia Lobby's authenticated transport without shipping tool in game. |
| [Playwright](https://github.com/microsoft/playwright) | Apache-2.0 | Already used. Expand deterministic real host+guest complete-match, viewports, reconnect and a11y assertions. Prefer this before introducing another game test framework. |
| [Spector.js](https://github.com/BabylonJS/Spector.js) | MIT | Developer-only WebGL frame diagnosis; never bundle diagnostics into public game. |
| [glTF-Transform](https://github.com/donmccurdy/glTF-Transform) | MIT | Use only when a licensed GLB is incorporated; offline texture/mesh compression and per-asset validation. |
| [Kenney Car Kit](https://kenney.nl/assets/car-kit) | CC0 on asset page | Candidate kart visual assets. Verify actual downloaded archive/license, every included source and scale/texture impact before use. |
| [Kenney Board Game Pack](https://kenney.nl/assets/boardgame-pack), [Board Game Info](https://kenney.nl/assets/board-game-info), [Board Game Icons](https://kenney.nl/assets/board-game-icons) | CC0 on asset pages | Candidate visual decoration for Sorry Ish, Poker, Family Showdown; no third-party proprietary game branding. |
| [axe-core](https://github.com/dequelabs/axe-core) | MPL-2.0 (with third-party notices) | Development/CI accessibility checks, especially phone tap targets and screen-reader semantics. |
| [Lighthouse](https://github.com/GoogleChrome/lighthouse) | Apache-2.0 | Benchmark host/phone loading and accessibility; report laptop/CI versus real Render/phone separately. |
| [Howler.js](https://github.com/goldfire/howler.js) | MIT | Optional small audio adapter if built-in Web Audio is insufficient; playback library includes no audio recordings. |
| [perfect-freehand](https://github.com/steveruizok/perfect-freehand) | MIT | Optional off-line comparison for stroke smoothing; only proceed if existing SVG regression tests show a measurable benefit. |
| [boardgame.io](https://github.com/boardgameio/boardgame.io) | MIT | **Reference patterns only** for deterministic moves/turns and state logs, not a replacement for current authorized game engine. |
| [Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing) | CC0 for structured statements; other text scopes differ | Curate and verify original quiz facts; never assume external images, page text or user question submissions share the CC0 license. |
| [Trivy](https://github.com/aquasecurity/trivy) | Apache-2.0 | Isolated CI vulnerability/misconfiguration/secret scanning, not user content extraction or a substitute for reviewing GitHub Actions. |

## Prioritized, reversible execution plan

1. **Safeguard data:** Resolve #48 with explicit owner-approved storage destination; inspect existing workflow and actual skipped backup job; prove encrypted independent snapshot + isolated DB and original-file restore before enabling schedule.
2. **Protect release controls:** Tighten #49 in GitHub settings (owner-only), require core CI and updated-branch policy if stable, request real independent review where possible. Prove rejection/acceptance on disposable PRs. Avoid changing required check contexts blindly.
3. **Complete release integration:** Current #121 is green on its own head, but #119 is already merged on main; confirm main guest-browser suite, then merge #121 only after reconciliation/review and rerun *all* tests on the resulting main. Render auto-deploy remains off. Do not deploy while backup/device release gates are unresolved without explicit owner decision.
4. **Performance baselines:** Record reproducible host 3D/2D p50/p95 with Spector.js diagnosis and existing measured-ui script; report WebGL renderer information and actual host hardware. Run limited 4/10/20 authenticated controllers, one and multiple rooms, with latency/failure observations. Avoid load testing public production without a bounded authorized test plan.
5. **31/31 completion:** Update matrix and issue #122 to acknowledge 2/31 verified matches, then add actual end-to-end completion for the other 29 in short batches; keep manual judge/dice cases labeled manual.
6. **Presentation and content:** Once the safety/performance baseline is established, address #98–#102 with isolated original CSS/SVG and audited CC0 assets first, alongside #121's rematch variety. No wholesale cloning of 15 open-party games or alternate multiplayer backend.
7. **Issue hygiene:** Update #49 (protection exists, hardening remains), #122 (29 pending), #100 (merged SVG improvement, remainder pending), and #51 (Sprint/Odd are implemented in main's private quiz path despite old #46/#47 being closed; require physical device acceptance). Review overlapping #12/#2/#19/#13 and roadmap #3/#14 without prematurely closing unsettled acceptance.
